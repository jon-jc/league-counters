# League Counters

A modern League of Legends counter-pick and tier-list tracker.

- **Tier lists** per region, rank, role and patch — recomputed from real ranked match data.
- **Counters & matchups** — per-champion win-rate deltas against every opponent in lane.
- **Multi-region** — data aggregated independently for each Riot platform.

Built with Next.js, TypeScript and React.
